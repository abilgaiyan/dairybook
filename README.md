# 🥛 DairyBook - Milk Management System

A complete dairy farm management system with:
- 📊 Milk production tracking
- 👥 Client dispatch management  
- 🧾 Automatic billing with fat-based pricing
- 🤖 AI Assistant (OpenRouter integration)
- 📱 WhatsApp bill sharing
- 🌐 Hindi/English bilingual support
- 📅 Fiscal year archiving (Apr-Mar)

## 🌐 Live Demo
https://abilgaiyan.github.io/dairybook/

## 🚀 Features
- Record milk sessions (morning/evening)
- Track per-animal production
- Manage client dispatches
- Generate monthly bills
- Share bills via WhatsApp
- AI-powered insights
- Auto fiscal year archive

## 🔧 Setup
1. Get OpenRouter API key from openrouter.ai
2. (Optional) Connect Google Sheets for cloud backup
3. Start recording!

## 📱 Access
Works on any device - mobile, tablet, desktop
